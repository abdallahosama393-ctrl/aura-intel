# Aura Intel

منصة ذكاء سوقي واقتصادي للمتاجر والشركات الرقمية في إندونيسيا. تدخل مدينة (Jakarta،
Surabaya، Makassar، ...) واسم منتج، فتحصل على تحليل أسعار، مؤشر طلب، تشبع سوق،
خريطة أبرز المنافسين، واتجاه 14 يومًا — كل ذلك عبر محاكاة حية مبنية على بذور
(seeds) مشتقة من المدينة والمنتج، وليست بيانات ثابتة مسبقة الصنع.

**Market & economic intelligence platform for digital merchants and companies
in Indonesia.** Enter a city and a product to get a pricing analysis, a demand
index, market saturation, a competitor snapshot, and a 14-day trend — all
generated by a seeded, per-city/per-product simulation, not static fixtures.

---

## Stack

| Layer      | Technology                                   |
|------------|-----------------------------------------------|
| Backend    | Python, FastAPI, Uvicorn                       |
| Frontend   | Jinja2, HTML5, Tailwind CSS (CDN), Chart.js    |
| i18n       | JSON dictionaries — Arabic (RTL), English, Bahasa Indonesia |
| Tests      | pytest + FastAPI `TestClient` (httpx)          |

No database is required — the market snapshot is computed on request by
`app/market_engine.py`.

## Setup

```bash
cd aura_intel
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python run.py
# or
uvicorn app.main:app --reload
```

Then open **http://127.0.0.1:8000/**. Switch language with the pills in the
top bar, or directly via `?lang=ar`, `?lang=en`, `?lang=id`.

## API

| Method | Path            | Description                                   |
|--------|-----------------|------------------------------------------------|
| GET    | `/`              | Renders the dashboard (server-rendered, pre-populated with a default snapshot) |
| POST   | `/api/analyze`   | `{ "city": "jakarta", "product": "Kopi Kemasan", "language": "en" }` → full market snapshot JSON |
| GET    | `/api/meta`      | Cities, sample products, and the active locale dictionary |
| GET    | `/health`        | Liveness check |

## Tests

```bash
pytest -v
```

The suite covers: page rendering and RTL/LTR direction per language, the
`/api/analyze` contract (schema, price ordering, bounded indices, sorted
competitors), input validation (blank/missing fields → 422), graceful
handling of an unlisted city, and the simulation engine directly (stable
snapshot shape, category-driven price bands, city-weight effects on
competitor counts).

## Notes on the simulation

`market_engine.build_market_snapshot(city, product)` combines:
- a **stable seed** from `hash(city, product)` — gives each city/product pair
  a consistent "market identity" (price band anchor, competitor roster), and
- a **live seed** from a 5-minute time bucket — adds small live jitter so
  repeated visits feel like a moving market rather than a frozen fixture.

This is a self-contained estimator for exploration and planning, not a feed
of real marketplace prices — the UI states this explicitly in the footer
disclaimer, in all three languages.
